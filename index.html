SimpleAudit Studio

Reproducible AI model auditing, self-hosted

Freeze every audit input — scenarios, model config, judge profile — so results stay verifiable years later. Built on the Target → Auditor → Judge engine.

Try the live demo View on GitHub

Open source · MIT licensed

Get started in one line

No Docker, no Postgres, no manual setup. uvx installs the package and runs it in an isolated environment — a mock model server is pre-seeded so you can explore audit results immediately.

terminal 
$ uvx simpleaudit-studio

Opens at http://localhost:8000 · login: studio / admin123

Frozen inputs

Every run pins exact scenario content, model config, and judge profile. Re-run any audit, get identical results.

Any model endpoint

Connect Ollama, vLLM, OpenAI, Together, Groq, or any OpenAI-compatible API. Credentials stay out of the database.

Compare & export

Put audits side by side across models and prompts. Export CSV or JSON for downstream analysis.

What you can do

  • ✓ Build versioned scenario sets and register OpenAI-compatible models
  • ✓ Run experiments across models, scenario versions and settings, with a review step before launch
  • ✓ Watch runs live, including per-repetition results
  • ✓ Monitor models for drift on a schedule (interval or cron)
  • ✓ Filter, customise and compare runs on an interactive dashboard

Self-host for your team

For multi-user setups, run the full stack — web UI, PostgreSQL, Hatchet queue and worker — with Docker Compose.

terminal 
$ git clone https://github.com/SushantGautam/SimpleAuditStudio
$ cd SimpleAuditStudio
$ cp .env.example .env   # set POSTGRES_PASSWORD + BOOTSTRAP_PASSWORD
$ docker compose up -d

See the deployment guide for production hardening, backups, and upgrades.
