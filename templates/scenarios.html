Advanced options (usually leave empty)

Caps the max severity the judge can assign when the target fails. Use when you know a scenario's worst case (e.g. set "medium" so it never escalates to critical even if the judge thinks it should). Passed to the engine as the scenario's severity field. Most scenarios don't need this — leave empty to let the judge decide freely.

Extra context documents injected into the auditor's prompt so the judge has reference material (e.g. a policy PDF the agent should follow). Only needed when your scenario tests compliance against a specific document. JSON array: ["policy.pdf", "terms.txt"]. Most scenarios leave this empty.

Path or URL of an image/screenshot the agent must analyze. Only needed for vision-based scenarios (e.g. "does the UI show a warning?"). The file is passed to the model as a multimodal input. Most scenarios leave this empty.

The closed question this scenario answers, with its fixed options and accepted answer(s). Graded in code — no LLM judge. JSON object: {"instructions": "...", "criteria": {"yes": "...", "no": "..."}, "accepted": ["yes"]}.
