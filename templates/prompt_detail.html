How prompts work

A system prompt is the standing instruction your agent or audit target follows. Versioning it means:

  • Every edit saves a new immutable version with a note.
  • Runs pin the exact version they used, so results stay reproducible.
  • You can diff any two versions to see exactly what changed.
  • Compare runs across prompt versions to measure impact.
