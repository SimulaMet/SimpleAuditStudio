{% comment %} Universal tooltips (included once by base.html). Any element with a `title`, and any icon-only button/link with an `aria-label`, shows a styled tooltip on hover and keyboard focus. Nothing to add per element: set title or aria-label. The native tooltip is suppressed by moving `title` into `data-tip` on first hover; scripts that later set `title` again (e.g. live refresh) still work. {% endcomment %}
