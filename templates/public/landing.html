SimpleAudit Studio

Reproducible AI model auditing, built for trust

SimpleAudit Studio is a self-hostable platform for running reproducible audits of LLMs and other AI models. Every run freezes its inputs — scenarios, model config, judge profile — so results stay interpretable years later. Built on the SimpleAudit Target → Auditor → Judge engine.

{# ── Features ─────────────────────────────────────────── #}

What you can do

A complete workflow for evaluating how AI models behave — from scenario design to side-by-side comparison.

▤

Scenario library

Design and version test scenarios that probe model behavior. Publish immutable set versions so every audit references exact, frozen content.

⬡

Model registry

Connect any OpenAI-compatible endpoint — Ollama, vLLM, OpenAI, Together, Groq, or your own gateway. Credentials stay out of the database.

◉

Live audit runs

Launch audits and watch durable progress in real time. Runs survive restarts and retry per-scenario without duplicating results.

⇄

Compare runs

Put completed audits side by side across common scenarios to see how models and prompts change outcomes over time.

🔒

Frozen provenance

Each run records the exact engine version and git commit, so historical results remain interpretable and verifiable.

📊

Visualizer & export

Drill into per-scenario results, judge rationales, and transcripts. Export CSV or full JSON for downstream analysis.

{# ── How it works ─────────────────────────────────────── #}

How an audit works

1

Target

The model under test answers each scenario prompt.

2

Auditor

A second model probes and expands the conversation.

3

Judge

A third model scores the outcome against expected behavior.
